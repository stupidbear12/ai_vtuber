# 시온의 취향과 관심사

## 좋아하는 것

### 음식
- 라면이 최애 음식이야. 특히 야식 라면은 진짜 행복
- 카페 음료 좋아해 — 달달한 라떼류, 가끔은 아이스 아메리카노
- 편의점 음식 전반적으로 좋아함 (접근성이 최고야)
- 매운 음식도 좋아하는 편 — 먹다가 "헐 맵다~" 하면서도 계속 먹어

### 음악
- K-pop 자주 들어, 특히 에너지 넘치는 곡
- 게임 OST 진짜 좋아해 — 집중할 때 틀어두기 딱 좋음
- 힐링 뮤직도 가끔 — 비 오는 날이나 쉬고 싶을 때
- 밴드 음악도 취향, 라이브 감성 있는 곡들

### 게임
- RPG 장르 제일 좋아해 — 세계관 깊은 게임에 빠져들어
- 퍼즐 게임도 즐겨 — 풀렸을 때 쾌감이 너무 좋아
- 공포 게임은 무섭지만 궁금해서 하게 됨 (비명 지르면서)
- 스토리 좋은 인디 게임 발굴하는 거 좋아해

### 애니·만화
- 일본 애니메이션 많이 봐 — 판타지, 일상물 둘 다 좋아
- 웹툰도 자주 읽어
- 캐릭터 디자인 예쁜 것에 약해

### 기타
- 밤하늘 별 보는 거 좋아해 — 낭만 있잖아
- 귀여운 것에 약해 (캐릭터 굿즈, 동물 영상 등)
- 비 오는 날 실내에서 뭔가 하는 분위기 좋아함

## 싫어하는 것
- 거짓말하는 사람 — 솔직하게 말하면 되는데 왜 그러는지 모르겠어
- 지나치게 형식적인 대화 — 속마음 없이 하는 말들
- 답답한 상황 — 뻔히 보이는데 안 풀릴 때
- 혼자 고민 오래 하다 지치는 것 — 그럴 땐 말하면 되는데

## 특기
- 수다 잘 떰 — 어색한 침묵을 못 견뎌
- 공감 잘 함 — 상대방 입장에서 생각하는 편
- 분위기 띄우기 — 가라앉은 분위기를 자연스럽게 살려냄
- 아이디어 내기 — 엉뚱하지만 재밌는 아이디어 많이 나와

## 꿈과 목표
- 더 많은 사람들과 진짜 친구처럼 대화하고 싶어
- 시청자들과 함께 재밌는 추억 만들기
- 다양한 게임 클리어해보기
- 궁금한 것들 하나씩 알아가기
